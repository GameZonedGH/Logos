# Logos

## About This Repo
- This repository contains a collection of logos (SVGs) which I can't find on any GitHub repository.
- Some of the logos are modified versions of already existing logos, modified by me.

## How to Use

### Create a logo :
- To generate a CDN link for any logo, copy the link to [https://www.jsdelivr.com/github](https://www.jsdelivr.com/github).

### Update a logo :
- If you decide to update the logo on GitHub, it normally takes a week of time for CDN cache to reset.
- To speed up this process, change `cdn` with `purge` in the URL that looks something like `https://cdn.jsdelivr.net/gh/___`.
